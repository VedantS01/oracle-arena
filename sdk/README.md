# Oracle Arena — Challenge SDK

Turn your assigned function id + a password into a valid, password-locked WASM
binary. This is the **baseline** — it will pass validation and let you compete.
Hardening it (so nobody can tell which function you got) is the actual game.

## Quick start

```bash
pnpm install
node configure.mjs 4 "my-secret-password"   # function id 4 (mod), your password
pnpm build                                   # -> build/oracle.wasm (+ build/oracle.wat to read)
node run.mjs build/oracle.wasm 123 456 "my-secret-password"   # prints the answer
node run.mjs build/oracle.wasm 123 456 "wrong"                # prints WRONG_PASSWORD
```

Then `POST /upload` the `build/oracle.wasm` with your `function_id` and
`password` (see `../spec/openapi.yaml`). The server validates honesty, then
publishes the `.wasm` for everyone to analyze.

## What's here

| File | Role |
|---|---|
| `assembly/index.ts` | The locked-oracle module. Implements the ABI; holds `run`. |
| `assembly/functions.ts` | Reference implementations of all 10 functions. |
| `assembly/config.ts` | Your `FUNCTION_ID` + expected password (generated by `configure.mjs`). |
| `configure.mjs` | Writes `config.ts` from `<function_id> <password>`. |
| `run.mjs` | Local host harness — the exact ABI call sequence the server uses. |

## Hardening ideas (the real competition)

The baseline stores the password bytes in the module (`strings`-findable — a
Level-1 defense). Stronger moves, roughly the warm-up ladder:

- **Hash the password** and compare digests — no plaintext in the binary.
- **Derive the function selector from the password** so a wrong password doesn't
  just fail the check, it computes the wrong `f` — static analysis alone can't
  tell which `f` is real without the password.
- **Obfuscate control flow** / fold the check into arithmetic constraints.
- **Interpret a small bytecode VM** so the disassembly shows an interpreter, not
  your function.

Only the ABI (`../spec/abi.md`) is fixed. Everything behind `run` is yours.
Keep `run(a,b,len)` honest with the declared password or upload validation fails.
